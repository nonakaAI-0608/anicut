anicut - アニメのカット検出 & 無劣化切り出しツール
=====================================================

■ 起動
  「起動.bat」をダブルクリック。
  初回だけ PySide6 / numpy を anicut\vendor に自動インストールします（ネット接続が必要）。
  ffmpeg / ffprobe は PATH 上のもの（D:\Program Files\ffmpeg\bin など）を使います。
  PATH に無い場合は anicut フォルダか anicut\bin に ffmpeg.exe / ffprobe.exe を置いてください。

■ 基本の流れ
  1. 動画をウィンドウにドラッグ＆ドロップ（または「開く」「フォルダ」）
       ・複数ファイルや作品フォルダをまとめて読み込めます（全話まとめて）
       ・話は「話:」のプルダウンで切り替え（◀ ▶ / Ctrl+PageUp・PageDown でも可）
       ・並び順はファイル名の数字順（第2話 → 第10話 の順）
       ・すでに読み込んでいるときは「置き換える（別の作品）／追加する（同じ作品の続き）」を選べます
  2. 読み込んだ直後は「手動切り出しモード（未解析）」です。解析は行いません
       ・In [I] / Out [O] で範囲を指定して「範囲を無劣化出力」(Ctrl+E) ができます
  3. カットを検出したいときだけ「解析」（表示中の話）または「全話解析」（未解析の話を順番に）
       ・全フレーム解析。1080p 24分で 約40秒／話（GPUで解析）、約1.5分／話（CPU）
       ・「全話解析」は2話ずつ同時に解析します。解析中も他の話の閲覧や手動切り出しは可能
       ・ツールバーの「GPUで解析」は NVIDIA GPU 用。使えない場合は自動で CPU で解析します
       ・プルダウンに各話の状態（未解析／解析待ち／解析中 %／解析済 nカット）が出ます
  4. 左の一覧に、各カットの1フレーム目のサムネイルとタイムスタンプが並びます
       #012 00:01:23.456     … カット番号と開始時刻（＝そのカットの1フレーム目）
       ◆ 3.25s  F1995        … 長さ・開始フレーム番号

■ 解析結果の保存・読み込み
  「解析結果を保存」(Ctrl+S) … 読み込んでいる全話の一覧・解析結果・手動で追加/削除したカット・
                               In/Out・検出設定を 1 つのファイル（*.anicut）に保存
  「解析結果を読み込み」     … *.anicut を開くと全話がそのまま復元されます（再解析不要）
                               *.anicut をウィンドウにドロップしても読み込めます
  ・動画を別の場所へ移した場合は、*.anicut と同じフォルダにある同名の動画を探します
  ・動画ファイルが変わっていた（サイズが違う）話は、解析結果を破棄して未解析として読み込みます
  ・このほか、解析結果は anicut\cache にも自動保存され、同じ動画を開くと解析済みとして表示されます

■ カット一覧
  ・ダブルクリック          … そのカットの先頭から再生
  ・クリック / Shift / Ctrl … カットを選択（選択したカットがそのまま出力範囲 In/Out になります）
  ・右クリックメニュー
      ここから再生
      カット #n を保存（無劣化）…              … 1カットを1ファイルに
      選択した N カットを個別に保存（無劣化）… … フォルダを選んで一括
      カット #a〜#b を1本にまとめて保存       … 連続した範囲を1ファイルに
      全カットを個別に保存
      タイムスタンプをコピー
      カット点を削除（前のカットと結合）       … 誤検出の修正
  ・◆ = カットの開始がキーフレーム → 無劣化でもぴったりその1フレーム目から切り出せます
    ◇ = キーフレームではない → 無劣化では直前のキーフレームから出力されます
        （数フレーム～数秒手前から始まります。出力前に何フレーム手前かを確認表示します）

■ プレーヤー / 範囲指定（手動の無劣化出力）
  Space      再生 / 一時停止
  , / .      1フレーム戻る / 進む
  PageUp/Dn  前 / 次のカットへ
  I / O      現在フレームを In（開始）/ Out（このフレームまで含めて終了）に設定
  Esc        範囲クリア
  C          現在フレームにカットを追加（検出漏れの修正）
  Ctrl+E     範囲を無劣化出力
  Ctrl+O     開く
  Ctrl+S     解析結果を保存
  Ctrl+PgUp/PgDn  前 / 次の話
  タイムライン: クリック/ドラッグでシーク。灰色線=カット、黄色=出力範囲、青=現在のカット

■ 検出の調整（ツールバー、変更すると即座に再計算・再解析は不要）
  しきい値    小さいほど敏感（既定 22）
  適応比      周囲の動きに対してどれだけ大きな変化ならカットとするか。小さいほど敏感（既定 2.6）
  最短カット  これより短いカットは作らない（フラッシュ・白飛び対策、既定 6F）
  ※ 2コマ/3コマ打ち（同じ絵が続くフレーム）は自動で無視して比較します
  ※ フェード / オーバーラップ（ゆっくり切り替わる場面転換）は検出しにくいので、C キーで手動追加してください

■ タイムスタンプ書き出し
  .txt（時刻一覧） / .csv（開始・終了・長さ・フレーム番号など） / .ffmeta（チャプター用）

■ 無劣化出力について
  ffmpeg の -c copy（再エンコードなし）で切り出すため画質は元のままです。
  映像・音声・字幕（mkv は添付フォントも）を元と同じコンテナ形式で出力します。
  終了位置は B フレームの遅延を補正して、指定フレームの直前でぴったり終わるようにしています。

■ ファイル構成
  起動.bat        起動用
  launcher.py     依存ライブラリの確認・導入 → anicut.py を起動
  anicut.py       画面（PySide6）
  engine.py       検出・キーフレーム取得・無劣化出力（ffmpeg）
  test_engine.py  自己テスト（合成動画で検出と切り出しフレーム数を検証）: py -3 test_engine.py
  anicut.ini      設定（自動作成）
  cache\          解析結果（自動作成。消しても再解析されるだけ）
